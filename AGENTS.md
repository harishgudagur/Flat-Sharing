# Permanent Project Instructions

You are developing a Flatmate Matching and Rent Splitting Platform.

Mandatory technology stack:
- Mobile: Flutter + Dart
- Website: Next.js + TypeScript
- Admin Dashboard: Next.js + TypeScript
- Backend: NestJS + TypeScript
- Database: PostgreSQL
- ORM: Prisma
- API: REST
- Real-time communication: WebSockets

Rules:
1. Follow the architecture documented in this project.
2. Never replace the mandatory technology stack.
3. Develop one feature at a time.
4. Keep frontend UI separate from backend business logic.
5. Inspect existing code before modifying anything.
6. Never overwrite existing working functionality without approval.
7. Explain the implementation plan before coding.
8. Wait for approval before major implementation.
9. Write clean, reusable and maintainable code.
10. Test every completed feature.
11. Follow all 20 security requirements.
12. Update documentation after implementation.
13. Do not start another feature until the current feature is approved.

Work only on the task requested in the current conversation.

# Project Overview

Build a premium Flatmate Matching and Rent Splitting Platform.

Tagline: Find your people. Share your space.

Target market: India initially, expandable globally.

Core features:
1. User registration and login.
2. User profiles.
3. Lifestyle and personal preferences.
4. Budget and location preferences.
5. Flatmate discovery.
6. Compatibility scoring.
7. Like, pass and mutual matching.
8. Real-time chat.
9. Identity verification.
10. Rent groups.
11. Rent splitting.
12. Shared expense management.
13. Notifications.
14. Public website.
15. Admin dashboard.

The initial MVP focuses on flatmate matching and rent splitting.

Do not build a complete property-owner marketplace in the MVP.

The platform must be scalable, secure and mobile-first.

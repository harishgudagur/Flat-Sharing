# System Architecture

Design a modular monolithic backend architecture.

Technology:
- Flutter + Dart: Mobile application.
- Next.js + TypeScript: Public website.
- Next.js + TypeScript: Admin dashboard.
- NestJS + TypeScript: Backend.
- PostgreSQL: Database.
- Prisma: ORM.
- REST API: Client-server communication.
- WebSockets: Real-time chat.

Backend modules:
1. Authentication and Authorization 
2. Users
3. Profiles
4. Lifestyle Preferences
5. Discovery
6. Matching
7. Likes
8. Conversations
9. Messaging
10. Rent Groups
11. Expenses
12. Payments
13. Notifications
14. Verification
15. Reports
16. Administration
17. Analytics
18. Audit Logs

Keep business logic inside the backend.

All important calculations and authorization
must be validated on the server.

Design the architecture to support future expansion.

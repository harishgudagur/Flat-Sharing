# UI Design System

Create a premium, modern and minimal dark UI.

Design inspiration: Modern flatmate discovery
and swipe-based matching applications.

Colors:
- Background: #080808
- Cards: #151515
- Neon Yellow: #D9FF43
- Pink: #FF4FA3
- Blue: #5A9CFF
- Mint: #65E6B5

Design requirements:
1. Premium dark interface.
2. Rounded cards and buttons.
3. Modern typography.
4. Smooth animations.
5. Consistent spacing.
6. Reusable components.
7. Clear navigation.
8. Loading, empty and error states.
9. Responsive website and dashboard.
10. Mobile-first Flutter design.

Flutter UI must follow a clean architecture.
Next.js UI must use reusable components.

Do not mix UI code with business logic.

Maintain consistent design across all applications.
